API Integration

Accept Quick Pay payments on your own website or app — step by step.

How it works
  1. Copy your Quick API key from Developer Portal → Quick API. Keep it on your server — never put it in public code.
  2. Create an order: POST /api/developer/create-order with { quick_api, amount, title }.
  3. Send your customer to the payment_url you get back — they pay on Quick Pay.
  4. Check the result: GET /api/developer/order-status/:orderId?quick_api=YOUR_KEY until the status is success or failed, then show your own success / failure screen.
Tip: switch to Test Mode (Quick API → Gateway Mode) to try the whole flow without real money.
